# NOVA Market

A responsive ecommerce storefront demo built with React and Vite.

## Features
- Responsive storefront with category filters and product search
- Sort products by featured, price, or rating
- Add and remove favourites
- Cart drawer with quantity controls and subtotal
- Demo checkout confirmation (no payment is collected)
- Mobile navigation and empty states

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

This is a front-end portfolio project. Inventory, accounts, orders, and payments are demo-only; no backend or real payment processing is connected.
